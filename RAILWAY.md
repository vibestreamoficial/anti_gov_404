# Chat global no Railway (outras pessoas veem as msgs)

## 1. Conta
https://railway.app → Login com GitHub

## 2. Novo projeto
New Project → Deploy from GitHub repo → `vibestreamoficial/anti_gov_404`

Se o repo estiver bagunçado, use o ZIP:
New Project → Empty → Upload / conectar CLI com a pasta do ZIP `anti_gov_404_full`

## 3. Config
- Start command: `npm install && npm start`
- Ou so: `npm start` (Railway roda install sozinho)
- Root: pasta com `package.json` e `server/`

## 4. Dominio
Settings → Networking → Generate Domain

## 5. Abrir
O link `.up.railway.app` e o chat GLOBAL.
Admin padrao no servidor Node: admin / admin123
(troque depois)

## 6. Divulgar
Manda o link do Railway, NAO o github.io, se quiser chat entre pessoas.
