# anti_gov_404 Sistema privado com painel administrativo, painel do dono e detector de ameaças/fake news/acusações falsas. ## O que foi ajustado - Removeu o uso de Supabase do front-end. - Cria um backend próprio com Express e PostgreSQL. - Mantém painel admin e painel do dono visíveis apenas para cargos autorizados. - A bot de moderação bloqueia mensagens com conteúdo proibido antes de enviar. - O chat é privado e exige autenticação. ## Requisitos - Node.js 18+ - PostgreSQL 14+ ## Instalação 1. Crie o banco PostgreSQL: ```bash createdb anti_gov_404 ``` 2. Copie o arquivo de ambiente: ```bash cp .env.example .env ``` 3. Ajuste as variáveis do banco e JWT. 4. Instale dependências: ```bash npm install ``` 5. Inicie o servidor: ```bash npm start ``` ## Fluxo - Cadastro cria usuário com status `pending`. - Admin aprova ou rejeita a solicitação. - Usuário aprovado entra no chat. - Bot bloqueia conteúdo suspeito. - Dono pode promover admins. ## Painel do Dono O dono é o único perfil com acesso completo ao gerenciamento de admins e visualização do sistema. ## Segurança - Senhas com hash via bcrypt - JWT para autenticação - Middleware de autorização por perfil - Conteúdo proibido detectado automaticamente antes do envio
